## Firmware
I got (hopefully) the firmware to show this image.

<img src=assets/photo.png alt="Photo on Hackpad" width="200"/>

It's made in QMK. The encoder controls volume, and LED brightness. The keys are currently mapped to F13-16!

## BOM
- 4x Cherry MX Switches
- 4x DSA Keycaps
- 4x SK6812 MINI-E LEDs
- 1x 0.91" 128x32 OLED Display
- 1x EC11 Rotary Encoder
- 1x XIAO RP2040
- 1x Case (2 printed parts)
